# DCShadow

<p className="glossary-answer">Te registras temporalmente como un DC malicioso, inyectas cambios en AD (añadir usuario a Domain Admins, modificar SIDHistory) y desapareces.</p>

**Categoría:** [Active Directory · Vectores avanzados](/glosario)

🎯 **Trinchera** — Te registras temporalmente como un DC malicioso,
inyectas cambios en AD (añadir usuario a Domain Admins, modificar
SIDHistory) y desapareces. Los cambios se replican por todo el bosque.

🔗 **Kill chain** — Requisito: Domain Admin. Variante usada para
**persistencia sigilosa** post-compromiso, no para escalar.

📡 **Huella defensiva** — `nTSecurityDescriptor` modificado fuera de
horario; `serverReference` añadido en Configuration NC.
Defender for Identity tiene detección dedicada.

⚠️ **Falso amigo** — Es post-explotación, no privesc. Usado para
backdoor tras conseguir DA.

🛡️ **Remediación** — Tier 0 estricto, monitor sobre Configuration NC,
auditoría de cambios en `Configuration\Sites\Default-First-Site-Name`.
