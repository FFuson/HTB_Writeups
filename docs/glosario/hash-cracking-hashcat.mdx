<p className="glossary-answer">hashcat GPU es el estándar para crackear hashes offline.</p>

**Categoría:** [Crypto práctica](/glosario)

🎯 **Trinchera** — `hashcat` GPU es el estándar para crackear
hashes offline. Modos clave:
- `0` MD5, `100` SHA1, `1400` SHA256.
- `1000` NTLM, `1100` Domain Cached.
- `5500` NetNTLMv1, `5600` NetNTLMv2.
- `13100` Kerberos TGS RC4 (Kerberoast).
- `18200` Kerberos AS-REP.
- `2100` MS Cache 2 (DCC2).

🔗 **Kill chain** — `hashcat -m <mode> hashes.txt rockyou.txt -r
OneRuleToRuleThemAll.rule`. Reglas multiplican wordlist (1
diccionario × 50k reglas = 50k variantes).

📡 **Huella defensiva** — Ofensivo offline; sin huella en target.

⚠️ **Falso amigo** — `OneRuleToRuleThemAll` es enorme (52k reglas),
úsalo con wordlist pequeña; `dive.rule` es buena alternativa.

🛡️ **Remediación** — Salting, KDFs lentos (Argon2id/bcrypt con
cost alto), políticas de pwd &gt; 14 chars, rotación.
