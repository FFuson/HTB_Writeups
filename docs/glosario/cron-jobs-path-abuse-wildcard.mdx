# Cron Jobs PATH abuse / wildcard

<p className="glossary-answer">Cron de root ejecutando script con PATH corto o sin path absoluto.</p>

**Categoría:** [Linux · Privilege Escalation](/glosario)

🎯 **Trinchera** — Cron de root ejecutando script con `PATH` corto
o sin path absoluto. Si el path incluye un directorio editable o
el script llama `tar /backup/*` y tienes write en `/backup`, creas
archivos con nombres como `--checkpoint-action=exec=sh shell.sh`.

🔗 **Kill chain** — Enumerar con `cat /etc/crontab; ls -la
/etc/cron*; pspy64`. Wildcard: tar, chown, chmod, rsync — todos
vulnerables si el dir es escribible.

📡 **Huella defensiva** — Auditd sobre `execve()` de cron;
modificación de archivos en directorios listados por scripts cron.

⚠️ **Falso amigo** — `pspy` es la única forma fiable de ver crons
runtime sin ser root (ver `/proc` snapshots).

🛡️ **Remediación** — Cron scripts con paths absolutos, no wildcards
en directorios escribibles, `Defaults env_reset` en sudoers.
