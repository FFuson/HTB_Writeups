# ECB mode cipher reuse

<p className="glossary-answer">ECB cifra cada bloque por separado.</p>

**Categoría:** [Crypto práctica](/glosario)

🎯 **Trinchera** — ECB cifra cada bloque por separado. Mismo
plaintext → mismo ciphertext. Patrones visibles, blocks
intercambiables. Famoso "Tux ECB".

🔗 **Kill chain** — Tokens generados con ECB pueden ser
re-ensamblados copy-pasting bloques entre tokens. Cookies
admin: bloques ECB → swap del bloque user→admin.

📡 **Huella defensiva** — Análisis estático del cipher mode si
es posible.

⚠️ **Falso amigo** — Algunos sistemas usan ECB sin saberlo (default
de algunas APIs viejas Java/PHP).

🛡️ **Remediación** — Nunca ECB. AES-GCM o XChaCha20-Poly1305.
