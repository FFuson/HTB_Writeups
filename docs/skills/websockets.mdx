# WebSockets Vulnerabilities

Esta página agrega los **recursos para practicar WebSockets Vulnerabilities** de forma cross-platform: máquinas retiradas de Hack The Box, labs de PortSwigger Web Security Academy y rooms de TryHackMe, más recursos curados (HackTricks, PortSwigger, etc.) y skills relacionadas.

**Cobertura:** 5 retos en 3 plataformas — 1 HackTheBox · 2 PortSwigger · 2 TryHackMe. 1 con writeup en español, 2 con writeup en vídeo.

## Por dónde empezar

Ordenado por dificultad real. A igual nivel, primero el lab aislado, después la room guiada y por último la máquina completa.

1. **PortSwigger** — [Manipulating WebSocket messages to exploit vulnerabilities](/portswigger/labs/websockets/manipulating-messages-to-exploit-vulnerabilities) (Apprentice) · 🇬🇧 📹

3. **TryHackMe** — [AWS API Gateway](/tryhackme/rooms/awsapigateway) (Medium · ~50 min) · 🇬🇧
4. **TryHackMe** — [Request Smuggling: WebSockets](/tryhackme/rooms/wsrequestsmuggling) (Medium · ~30 min) · 🇬🇧
5. **HackTheBox** — [MultiMaster](/htb/machines/windows/insano/multimaster) (Insano) · 🇪🇸 🇬🇧 📹
