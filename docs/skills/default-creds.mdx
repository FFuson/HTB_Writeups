# Credenciales por defecto

Esta página agrega los **recursos para practicar Credenciales por defecto** de forma cross-platform: máquinas retiradas de Hack The Box, labs de PortSwigger Web Security Academy y rooms de TryHackMe, más recursos curados (HackTricks, PortSwigger, etc.) y skills relacionadas.

**Cobertura:** 4 retos en 2 plataformas — 1 HackTheBox · 3 TryHackMe. 1 con writeup en español, 2 con writeup en vídeo.

Ordenado por dificultad real. A igual nivel, primero el lab aislado, después la room guiada y por último la máquina completa.
