# AS-REP Roasting

This page aggregates **cross-platform resources to practice AS-REP Roasting**: retired Hack The Box machines, PortSwigger Web Security Academy labs and TryHackMe rooms, plus curated resources (HackTricks, PortSwigger, etc.) and related skills.

**Coverage:** 5 challenges across 2 platforms — 2 HackTheBox · 3 TryHackMe. 2 with a Spanish writeup, 2 with a video writeup.
